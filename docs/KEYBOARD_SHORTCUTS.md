# Keyboard Shortcuts

PromptVault supports keyboard shortcuts to speed up navigation and editing.

## Main Shortcuts

- `Ctrl/Cmd + H`: Open version history for the selected prompt
- `Ctrl/Cmd + N`: Open the new prompt editor
- `Escape`: Close open dialogs and editor panels
- `?`: Open keyboard shortcuts and landmarks help modal

## Notes

- `Ctrl` applies on Windows/Linux, `Cmd` applies on macOS.
- Version history (`Ctrl/Cmd + H`) requires a selected prompt.
- The `?` help modal also lists detected page landmarks (`banner`, `navigation`, `main`, `complementary`, `contentinfo`).
