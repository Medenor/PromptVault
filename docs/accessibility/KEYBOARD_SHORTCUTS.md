# Keyboard Shortcuts

PromptVault supports keyboard shortcuts to speed up navigation and editing.

## Main Shortcuts

- `Ctrl/Cmd + H`: Open version history for the selected prompt
- `Ctrl/Cmd + N`: Open the new prompt editor
- `Escape`: Close open dialogs and editor panels
- `?`: Open keyboard shortcuts and landmarks help modal

## Filter Lists (Categories/Tags)

- `Arrow Up` / `Arrow Down` (`Arrow Left` / `Arrow Right`): Move focus between filter items
- `Home` / `End`: Jump to first/last filter item
- `Enter` / `Space`: Activate focused filter item
- `Any letter/character`: Jump to next filter item starting with that character (including CJK characters)

## Lists & Tables (Prompts, Versions, Admin/Management Tables)

- `Any letter/character`: Jump to the next matching item in:
- Prompts grid (focus moves to the prompt checkbox)
- Version history list (focus moves within version items)
- Categories/Tags management tables (focus moves to the row checkbox)
- Admin Users table (focus moves to the View button)
- Admin Sessions table (focus moves to the Revoke button)

## Notes

- `Ctrl` applies on Windows/Linux, `Cmd` applies on macOS.
- Version history (`Ctrl/Cmd + H`) requires a selected prompt.
- The `?` help modal also lists detected page landmarks (`banner`, `navigation`, `main`, `complementary`, `contentinfo`).
