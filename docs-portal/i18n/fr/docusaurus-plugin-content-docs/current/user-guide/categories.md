# Catégories

Les catégories attribuent à chaque prompt un regroupement principal unique — utile pour de grandes familles comme « Rédaction » ou « Revue de code » — gérées depuis la page Gérer les catégories.

## Créer et modifier {#creating-and-editing}

Une catégorie possède un nom, une description facultative, une couleur facultative (pour une identification visuelle rapide dans la grille), et un ordre de tri déterminant sa position dans les listes de catégories. Les noms doivent être uniques ; renommer une catégorie n'est qu'une modification, pas une nouvelle catégorie.

## Attribuer une catégorie à un prompt {#assigning-a-category-to-a-prompt}

Un prompt a au plus une catégorie, définie lors de sa création ou de sa modification. Attribuer un nom de catégorie existant le réutilise ; saisir un nom qui n'existe pas encore le crée immédiatement.

## Filtrer par catégorie {#filtering-by-category}

La grille principale des prompts peut être filtrée sur une seule catégorie à la fois, réduisant l'affichage aux prompts de ce groupe.

## Suppression, fusion et nettoyage {#deleting-merging-and-cleanup}

Supprimer une catégorie encore attribuée à des prompts nécessite une confirmation explicite « forcée », car cela retire la catégorie de tous les prompts concernés. Les catégories peuvent aussi être **fusionnées** — en regroupant une ou plusieurs catégories sources dans une seule catégorie cible, réattribuant tous les prompts concernés — ou renommées partout à la fois via **rechercher-remplacer**. Ces deux actions, ainsi que la suppression, peuvent être annulées immédiatement après si vous changez d'avis.
