# Documentation PromptVault

PromptVault est une application de gestion de prompts auto-hébergée. Ce portail couvre tout ce dont vous avez besoin pour l'installer, le configurer et utiliser ses fonctionnalités principales au quotidien.

## Pour commencer {#getting-started}

Nouveau sur PromptVault ? Commencez par [Installation](installation/index.md) pour obtenir une instance fonctionnelle, puis [Configuration](configuration/index.md) pour l'adapter à votre environnement.

## Guide utilisateur {#user-guide}

Une fois installé, le [Guide utilisateur](user-guide/versioning.md) couvre le versionnage des prompts, les sauvegardes, le partage, la recherche et l'authentification à deux facteurs.

## Un problème ? {#something-not-working}

Consultez [Dépannage](troubleshooting/index.md) pour les problèmes les plus courants, ou les [Notes de version](release-notes/index.md) pour connaître les changements récents.

## Développement / API

Reliez vos scripts et outils à [l’API existante](developer-api/index.md). Commencez par un appel guidé, puis consultez la référence servie par votre propre instance PromptVault.
