# Categorías

Las categorías dan a cada prompt una única agrupación de nivel superior — útil para grandes bloques como "Redacción" o "Revisión de código" — gestionadas desde la página Gestionar categorías.

## Crear y editar

Una categoría tiene un nombre, una descripción opcional, un color opcional (para una identificación visual rápida en la cuadrícula) y un orden de clasificación que determina su posición en las listas de categorías. Los nombres deben ser únicos; renombrar una categoría es solo una edición, no una categoría nueva.

## Asignar una categoría a un prompt

Un prompt tiene como máximo una categoría, definida al crearlo o editarlo. Asignar el nombre de una categoría existente la reutiliza; escribir un nombre que aún no existe la crea al instante.

## Filtrar por categoría

La cuadrícula principal de prompts puede filtrarse por una única categoría a la vez, reduciendo la vista a los prompts de ese grupo.

## Eliminación, fusión y limpieza

Eliminar una categoría que todavía está asignada a prompts requiere una confirmación explícita "forzada", ya que esto elimina la categoría de todos los prompts afectados. Las categorías también pueden **fusionarse** — combinando una o varias categorías de origen en una sola categoría de destino, reasignando todos los prompts afectados — o renombrarse en todas partes a la vez mediante **buscar y reemplazar**. Ambas acciones, junto con la eliminación, pueden deshacerse inmediatamente después si cambias de opinión.
