# Paginación

La cuadrícula principal de prompts carga los resultados página por página en lugar de obtener toda tu biblioteca de una sola vez, manteniendo rápida la carga inicial incluso con una colección grande.

## Cargar más

Cuando hay más prompts disponibles de los que muestra la página actual, un control "Cargar más" obtiene la siguiente página y la añade a lo que ya se muestra, sin perder tu posición. Una vez cargados todos los prompts, el control desaparece.

## Tamaño de página

Puedes elegir un tamaño de página de 25, 50 o 100 prompts; si no eliges ninguno, PromptVault carga 50 a la vez por defecto. Solicitar un tamaño de página superior a 100 se limita a 100 en lugar de rechazarse.

## Paginación y filtros

Aplicar un filtro de [categoría](./categories.md) o de [etiqueta](./tags.md), o una consulta de [búsqueda](./search.md), pagina el conjunto de resultados filtrado, no tu biblioteca completa — y cambiar cualquier filtro siempre te devuelve a la primera página.
