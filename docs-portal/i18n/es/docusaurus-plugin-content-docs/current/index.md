# Documentación de PromptVault

PromptVault es una aplicación de gestión de prompts autoalojada. Este portal cubre todo lo que necesita para instalarla, configurarla y usar sus funciones principales en el día a día.

## Primeros pasos

¿Nuevo en PromptVault? Comience con [Instalación](installation/index.md) para tener una instancia en funcionamiento, y luego [Configuración](configuration/index.md) para adaptarla a su entorno.

## Guía del usuario

Una vez instalado, la [Guía del usuario](user-guide/versioning.md) cubre el versionado de prompts, las copias de seguridad, el uso compartido, la búsqueda y la autenticación de dos factores.

## ¿Algo no funciona?

Consulte [Solución de problemas](troubleshooting/index.md) para los problemas más comunes, o las [Notas de la versión](release-notes/index.md) para ver los cambios recientes.

## Desarrollo / API

Conecte scripts y herramientas mediante la [API existente](developer-api/index.md). Siga una solicitud guiada y consulte después la referencia de su propia instancia de PromptVault.
