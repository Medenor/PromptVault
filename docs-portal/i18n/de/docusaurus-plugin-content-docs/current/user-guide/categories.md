# Kategorien

Kategorien geben jedem Prompt eine einzelne übergeordnete Gruppierung — nützlich für grobe Bereiche wie „Schreiben" oder „Code-Review" — verwaltet über die Seite Kategorien verwalten.

## Erstellen und Bearbeiten {#creating-and-editing}

Eine Kategorie hat einen Namen, eine optionale Beschreibung, eine optionale Farbe (zur schnellen visuellen Erkennung im Raster) und eine Sortierreihenfolge, die ihre Position in Kategorielisten bestimmt. Namen müssen eindeutig sein; das Umbenennen einer Kategorie ist nur eine Bearbeitung, keine neue Kategorie.

## Einem Prompt eine Kategorie zuweisen {#assigning-a-category-to-a-prompt}

Ein Prompt hat höchstens eine Kategorie, die beim Erstellen oder Bearbeiten festgelegt wird. Die Zuweisung eines vorhandenen Kategorienamens verwendet diesen wieder; die Eingabe eines noch nicht existierenden Namens erstellt ihn sofort.

## Nach Kategorie filtern {#filtering-by-category}

Das Haupt-Prompt-Raster kann jeweils auf eine einzelne Kategorie gefiltert werden, wodurch die Ansicht auf die Prompts dieser Gruppe eingegrenzt wird.

## Löschen, Zusammenführen und Bereinigung {#deleting-merging-and-cleanup}

Das Löschen einer Kategorie, die noch Prompts zugewiesen ist, erfordert eine explizite „erzwungene" Bestätigung, da dies die Kategorie von allen betroffenen Prompts entfernt. Kategorien können auch **zusammengeführt** werden — dabei werden eine oder mehrere Quellkategorien in eine einzige Zielkategorie zusammengefasst und alle betroffenen Prompts neu zugewiesen — oder überall gleichzeitig über **Suchen und Ersetzen** umbenannt werden. Beide Aktionen sowie das Löschen können unmittelbar danach rückgängig gemacht werden, falls Sie Ihre Meinung ändern.
