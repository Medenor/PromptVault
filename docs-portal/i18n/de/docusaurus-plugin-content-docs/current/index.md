# PromptVault-Dokumentation

PromptVault ist eine selbst gehostete Anwendung zur Prompt-Verwaltung. Dieses Portal deckt alles ab, was Sie zur Installation, Konfiguration und täglichen Nutzung der wichtigsten Funktionen benötigen.

## Erste Schritte

Neu bei PromptVault? Beginnen Sie mit [Installation](installation/index.md), um eine laufende Instanz zu erhalten, und dann mit [Konfiguration](configuration/index.md), um sie an Ihre Umgebung anzupassen.

## Benutzerhandbuch

Nach der Installation deckt das [Benutzerhandbuch](user-guide/versioning.md) Prompt-Versionierung, Backups, Freigabe, Suche und Zwei-Faktor-Authentifizierung ab.

## Funktioniert etwas nicht?

Prüfen Sie die [Fehlerbehebung](troubleshooting/index.md) für die häufigsten Probleme oder die [Versionshinweise](release-notes/index.md) für die neuesten Änderungen.
