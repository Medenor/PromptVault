# Categories

Categories give each prompt a single top-level grouping — useful for broad buckets like "Writing" or "Code Review" — managed from the Manage Categories page.

## Creating and Editing

A category has a name, an optional description, an optional color (for quick visual identification in the grid), and a sort order controlling where it appears in category lists. Names must be unique; renaming a category is just an edit, not a new category.

## Assigning a Category to a Prompt

A prompt has at most one category, set when creating or editing it. Assigning an existing category name reuses it; typing a name that doesn't exist yet creates it on the spot.

## Filtering by Category

The main prompt grid can be filtered to a single category at a time, narrowing the view to just that group's prompts.

## Deleting, Merging, and Cleanup

Deleting a category that's still assigned to prompts requires an explicit "force" confirmation, since doing so removes the category from every prompt that had it. Categories can also be **merged** — folding one or more source categories into a single target category, reassigning every affected prompt — or renamed everywhere at once via **find-and-replace**. Both actions, along with delete, can be undone immediately afterward if you change your mind.
