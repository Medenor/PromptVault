# PromptVault Documentation

PromptVault is a self-hosted prompt management application. This portal covers everything you need to install it, configure it, and use its core features day to day.

## Getting Started

New to PromptVault? Start with [Installation](installation/index.md) to get a running instance, then [Configuration](configuration/index.md) to tune it for your environment.

## User Guide

Once installed, the [User Guide](user-guide/versioning.md) covers prompt versioning, backups, sharing, search, and two-factor authentication.

## Something Not Working?

Check [Troubleshooting](troubleshooting/index.md) for the issues most people hit, or the [Release Notes](release-notes/index.md) for what changed recently.
